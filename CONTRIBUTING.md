# Contributing to PatchCTL

PatchCTL is an open-source project maintained by a solo developer with coding-agent assistance.
Focused fixes, reproducible bug reports, tests, and documentation improvements are welcome.

- Read [AGENTS.md](AGENTS.md) and the [Engineering Handbook](docs/ENGINEERING-HANDBOOK.md).
- For substantial changes, check [existing issues](https://github.com/hadoan/PatchCTL/issues)
  and [Project 7](https://github.com/users/hadoan/projects/7) before proposing overlapping work.
  Small fixes do not need a preliminary issue or assignment.
- Use a branch/fork and a focused PR for contributions. Describe the problem, change, checks,
  and remaining risks; include rendered evidence for UI changes. Drafts are welcome.
- Use the root pnpm workspace, existing feature patterns, and synthetic test data. Verify changed
  behavior using the handbook; do not point test or seed commands at production.
- Keep credentials, personal data, and private logs out of public discussions and commits.
  Raise suspected security issues privately with the maintainer through an available private channel.
- Preserve the repository's existing license and notices. Do not add an unrelated CLA or change
  licensing as part of routine implementation.

Agent-assisted contributions follow the same correctness and safety standards. Agent self-review
is useful evidence, not a claim of independent human review. No second reviewer or team ceremony
is required by this handbook; repository checks and maintainer decisions still govern acceptance.

Most importantly: agents may prepare content proposals, but authorized human review remains
mandatory before those proposals change live content.
